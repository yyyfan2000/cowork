# 协同办公应用

> 让协同办公少点几步、少等几次、少切几个系统。

协同办公应用是一款面向中大型企业的移动优先智能办公产品原型，聚焦员工每天最常遇到的五类高频场景：**会议预定、流程审批、差旅出行、文档查询、请假打卡**。

它不是再造一个“大而全”的办公平台，而是把原本分散在 OA、会议室系统、差旅平台、知识库和考勤工具里的关键动作，收敛到一个更轻、更快、更懂上下文的移动工作台里。

## 为什么值得关注

企业协同的低效，往往不是来自某个单点功能缺失，而是来自一连串细碎摩擦：

- 订会议室要反复找空房、比容量、看设备。
- 审批信息不完整，管理者要来回追问。
- 出差申请、订票、打卡、报销散落在不同系统。
- 制度文档版本太多，员工不知道哪份才是最新。
- 打卡异常、补卡、团队出勤统计依赖人工提醒和整理。

这个项目的核心思路是：**把高频办公动作做短，把上下文交给系统，把判断依据提前给到人。**

## 产品亮点

### 1. 一个入口处理每日待办

首页聚合审批、会议、出差、打卡异常等事项，让员工打开应用就能知道今天要处理什么。系统会根据场景状态触发提醒，例如到公司后提示打卡、出差结束后提示生成报销单、会议开始前提示签到。

### 2. 会议室从“人工找”变成“智能推荐”

会议模块支持查看当前可用会议室，并根据会议时间、人数、距离、设备需求推荐更合适的会议室。配合会前签到、提前结束、延长会议和行政看板，帮助企业减少会议室空占和资源浪费。

### 3. 审批不只是流转，而是辅助决策

审批模块覆盖请假、出差、报销等常见流程。管理者可以集中查看待办，审批详情里前置展示发起人、申请内容、状态流转和备注信息，减少“先退回去问清楚”的沟通成本。

### 4. 差旅打通申请、推荐、订票和报销

差旅模块围绕真实出差链路设计：填写目的地和时间后查看交通、酒店等推荐方案；审批通过后进入预订；出差结束后可汇总费用并生成报销申请。员工少填表，企业也更容易管控差旅成本。

### 5. 文档查询强调“找到正确版本”

文档模块支持搜索、分类筛选、标签、版本状态和 Markdown 内容展示。员工查询制度或流程时，可以优先看到最新有效版本，并获得相关文档推荐，减少翻旧文档、问同事、找错制度的情况。

### 6. 打卡与异常处理更贴近真实场景

考勤模块支持上班打卡、外勤打卡、忘打卡补卡、团队出勤看板等场景。应用通过 Wi-Fi、定位、出差状态等上下文做提醒，让考勤从“事后追补”变成“及时发现、及时处理”。

## 核心功能

| 模块 | 主要能力 | 解决的问题 |
| --- | --- | --- |
| 首页工作台 | 今日待办、智能提醒、快捷入口、状态模拟 | 打开应用后快速知道下一步要做什么 |
| 会议预定 | 空闲会议室、一键预订、智能推荐、会议签到、行政看板 | 降低找会议室成本，减少空占浪费 |
| 流程审批 | 请假/出差/报销审批、审批详情、批量处理、拒绝原因 | 提升审批效率，让决策信息更完整 |
| 差旅出行 | 出差申请、行程推荐、关联制度、预订与报销衔接 | 打通出差从申请到报销的完整链路 |
| 文档查询 | 搜索、分类、版本状态、AI 摘要式内容呈现、关联推荐 | 帮员工快速找到可信的最新资料 |
| 请假打卡 | 上班打卡、外勤打卡、补卡申请、团队考勤 | 减少打卡遗漏和人工统计成本 |

## 本地运行

### 环境要求

- Node.js 18 或更高版本
- Gemini API Key，用于启用相关 AI 能力

### 安装依赖

```bash
cd 协同办公应用
npm install
```

### 配置环境变量

复制环境变量示例文件，并填入你的 Gemini API Key：

```bash
cp .env.example .env.local
```

`.env.local` 中需要配置：

```bash
GEMINI_API_KEY=your_gemini_api_key
```

### 启动开发服务器

```bash
npm run dev
```

访问：

```text
http://localhost:3000
```

### 构建生产版本

```bash
npm run build
npm run preview
```

## 设计原则

- **移动优先**：优先服务员工在手机上快速完成动作的场景。
- **少填少跳**：把常用流程压缩到更短路径，减少系统切换。
- **上下文驱动**：用位置、时间、出差状态、审批状态等上下文触发合适提醒。
- **决策前置**：把审批、预订、报销所需的关键信息提前展示。
- **AI 融入流程**：让 AI 参与推荐、摘要、预填和关联，而不是成为孤立功能。
